# ConsciousnessResonanceBridge

Structured-vs-random pattern robustness study.

This repo now treats `consciousness-like` patterns as structured input classes,
not as a proof claim already settled by the simulator.

## Evidence tracks

- `simulation_baseline`: structured patterns vs random patterns under controlled
  perturbation
- `hardware_derived_model`: the same comparison under calibration-anchored
  noise severity
- `external_validation`: pending

## Quick Start

```bash
python3 'Consciousness-Resonance Bridge.py' --mode simulation --json
python3 'Consciousness-Resonance Bridge.py' --mode hardware-derived --json
```
