# Method

This repo asks whether structured patterns remain more recoverable than random
patterns under perturbation.

That is a legitimate robustness question. It is not, on its own, proof that the
patterns correspond to consciousness in an external ontological sense.

The current code supports:

- a simulation baseline
- a hardware-derived perturbation level driven by calibration-style parameters

The external step is still required.

Within the larger stack, this repo should be read as an interface layer between
the measurable cadence program and the broader architecture/ontology layer.
